### M-38. CLJS namespace rename — re-frame.substrate.<name> -> re-frame.adapter.<name>

This heading's slug is generated by `pymdownx.slugs.slugify(case='lower')`,
which strips the `<name>` placeholder text entirely.  GitHub — which actually
renders this README — escapes the angle brackets and keeps `name` as literal
text, so the two disagree here.

This is the one measured base-slug divergence between the shared slugifier and
GitHub's (rf2-zzt2r), and no heading in the live README corpus exercises it
(0 divergences over 545 headings).  The fixture pins the current behaviour so
the gap stays visible rather than drifting silently; closing it needs a
GitHub-specific base slugifier.  The duplicate-heading rule, by contrast, IS
GitHub's — see the `*_dup_*` fixtures.
