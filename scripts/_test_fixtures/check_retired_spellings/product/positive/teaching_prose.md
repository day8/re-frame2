# POSITIVE fixture (rule g) — the product named in ordinary prose

Rules (a)-(f) mask comments and read only fenced code, because their retired
spellings are ordinary vocabulary that prose must stay free to name. A product
name is not like that: outside the one rostered quotation there is no reason to
write it, so a heading, a sentence and a comment are all findings.
