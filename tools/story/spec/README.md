## How to use

This folder is complete enough to one-shot the tool. Read [`000-Vision.md`](000-Vision.md) first to anchor scope and the relationship to framework [`spec/007-Stories.md`](../../../spec/007-Stories.md); the capability docs (001–015) are normative — Stage 2 implements 001, Stage 3 implements 002, and so on. [`017-Testing-Story.md`](017-Testing-Story.md) is the Story-as-test substrate source of truth. [`018-Story-UI-North-Star.md`](018-Story-UI-North-Star.md) is the orientation read for the Story-UI target workshop, with the deeper per-surface contracts in `019`–`022` (controls / inspector+Xray / test+evidence / docs+share). [`Principles.md`](Principles.md) and [`DESIGN-RATIONALE.md`](DESIGN-RATIONALE.md) capture the locks. [`API.md`](API.md) is the consolidated public-surface reference. `findings/` preserves the audit lineage and is never normative.
