## 4. The advantage thesis, from re-frame2's substrate

`018-Story-UI-North-Star.md` §3.1 is the claim under test: "Parity is a quality bar, not a checklist of nouns… Story should deliberately surpass Storybook where re-frame2 gives leverage", with eight surpass items and four patterns not to copy.

### 4.1 The substrate levers

Five things a component-story tool for React, Vue or Swift does not have: **frames** (`spec/002`, `frames.cljc:18`) — an app-db, registrar view and effect table per variant, so nine states are nine isolated apps and a stub is a per-frame override, not a module mock (state isolation, not document isolation — A7); **epochs and the trace bus** (`spec/009`) — every dispatch a recorded beat, so the run result *is* evidence; **schemas → controls** (`spec/010`); **effects as data** — an emitted effect is an assertion and a replaced one a decorator tuple, both in the plan hash; **data-only registration** (`spec/007`) — no function slots, so a variant is diffable, promotable, transmittable over MCP, identical on JVM and CLJS. Storybook's equivalents are `play`, opaque decorators, `sb.mock`/MSW and CSF. None of this is impossible in JavaScript (astra), so the advantage has to show up as fewer translations between activities; Nubank workspaces and Portfolio did the component grid first (grok).
