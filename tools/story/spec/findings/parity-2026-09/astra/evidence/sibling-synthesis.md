## New analysis resulting from synthesis

The highest-value property to test is **preserving scenario intent across transformations and projections**: edited controls, compiled setup, run, explanation, promoted test and visual comparison. This follows from the original parity thesis; it is not a new framework abstraction. The current failures occur between working pieces. A few round-trip checks and better defaults can improve several workflows without adding public concepts.

Three falsifiable future journeys now sit in the main report: explore/retain/strengthen, failure/cause/regression, and human/agent/verified revision. The comparison should count lost expectations and repeated work, not merely files or UI panels. A richer evidence map that does not shorten diagnosis is not yet a demonstrated ergonomic advantage.

The visual recommendation now distinguishes **case identity** from **content provenance**. A case must still compare with its approved predecessor when application content changes. Newly seen hashes are not permission to accept new pixels. This is an inference from normal comparison semantics and [Playwright's documented reference workflow](https://playwright.dev/docs/test-snapshots), offered as a concrete acceptance condition.
