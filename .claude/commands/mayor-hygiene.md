description: Mayor Loop — worktree hygiene (≈60m cadence). Prune merged worktrees/branches; never touch open-PR worktrees.
---
MAYOR LOOP (worktree hygiene). Run `git worktree list`, `git branch --list 'worker/*'`, `git branch -r --list 'origin/worker/*'`. For each worker worktree: verify its PR via `gh pr view <#> --json state` — only if state==MERGED, prune it — but mind the `node_modules` junction. Worker worktrees junction `implementation/node_modules` into the mayor checkout's REAL `node_modules`, so `git worktree remove` (especially `--force`) follows that reparse point and deletes THROUGH it, emptying the mayor's real `node_modules`; recovery is `npm ci --prefix implementation` from the mayor checkout, and until someone notices every gate run from the mayor checkout fails looking like something else. So, in order: (1) check whether the worktree actually HAS a junction before touching it — PowerShell-native, with `$p` set to the forward-slash path of `<worktree>/implementation/node_modules`: `$i = Get-Item $p -Force -ErrorAction SilentlyContinue; if ($i -and $i.LinkType) { [System.IO.Directory]::Delete($p, $false) }` (only an actual reparse/link is removed, WITHOUT recursing into its target — the `$false` is non-recursive, dropping the junction and never the target). A spec-only or fresh worktree may have NO junction — an ordinary `Attributes=Directory` with no `LinkType`, possibly nonempty — which is ordinary worktree content: leave it and skip straight to (3); (2) only when you did neutralize a junction, VERIFY it is gone — `Test-Path $p` must print `False` — before removing; (3) THEN `git worktree remove <path>`. Never chain neutralize+remove in a single step. Canary each reap batch against a count captured at runtime, not a committed number: in the mayor tree take `$baseline = (Get-ChildItem implementation/node_modules).Count` BEFORE the batch, and require `(Get-ChildItem implementation/node_modules).Count` to equal `$baseline` AFTER — a smaller count means a junction was followed and the mayor tree needs recovery via `npm ci --prefix implementation` from the mayor checkout. (On Windows a shadow-cljs/Node JVM may still hold a file lock and removal fails with "Device or resource busy" / "Permission denied" — that is harmless, leave it locked and note it.) Delete merged local + origin worker branches (NEVER delete a branch whose PR is not verifiably MERGED). Then `git remote prune origin` for stale tracking refs and clear any stray stashes. NEVER touch a worktree whose PR is still open. Report what was pruned, what was left locked, and which (if any) needs a process-kill or reboot to clear.
