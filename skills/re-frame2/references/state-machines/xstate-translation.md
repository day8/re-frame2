# XState → re-frame2 translation catalogue

## When to load

Reach for this leaf when you have an xstate concept in hand (a state chart sketched the JS way, or a recalled `assign` / `invoke` / `setup` helper) and need its exact re-frame2 spelling — plus the rows where re-frame2 **renames or omits** the xstate slot, which is where xstate-trained intuition steers you wrong. For the declaration grammar itself, see [`reg-machine.md`](reg-machine.md); for the machine `:schemas` contract, [`machine-schemas.md`](machine-schemas.md).

> **Parity target is XState v6 semantics (EP-0029), not exact compat with an alpha.** re-frame2 aims at v6's design principles — plain functions over declarative topology, broader optional schemas, explicit timeouts, choice states, internal events — and many divergences below are *toward* v6 (it removes the v5 helper creators `assign` / `sendTo` / `raise` / `enqueueActions` / `and`/`or`/`not` and the `setup()` registry, which re-frame2 never had). When your training recalls a v5 helper creator, reach for the re-frame2 data-first form below, not a Clojure clone. **`stateIn` is the exception to read carefully:** re-frame2 ships no such *creator*, but it does ship the cross-region *behaviour* — see the **`stateIn(...)`** row below rather than concluding the capability is absent.

Most concepts map cleanly. A handful of slots re-frame2 renames or omits — watch the flagged divergence rows.

| xstate concept | re-frame2 equivalent | Notes / divergence |
|---|---|---|
| **states** (`state.value`) | `:states` map + the snapshot's `:state` slot | Flat → single keyword; compound → vector path; parallel → region-name→keyword map. Convergence. |
| **transitions** (`on: { EVENT: ... }`) | `:on {event-keyword transition-spec}` on a state node | Convergence. Bare-target / explicit-map / guarded-vector forms. |
| **wildcard / partial event descriptors** (`'*'`, `'mouse.*'`) | the `:*` (total) and `:ns/*` (namespace) keys in `:on` | Convergence on the concept. `:on` resolves **three descriptor tiers, most-specific-first** — exact → `:ns/*` → `:*` — and each wildcard is the least-priority *enabled* candidate at its level: a **guard-blocked** exact falls through to the same level's `:ns/*` then `:*` *before* any ancestor is consulted. **Divergence (segmentation):** XState/SCXML prefix-match on the `.` token at any depth (`a.*` matches `a.b.c`); re-frame2 segments on the keyword's `/` namespace boundary and offers a **single** prefix tier, so `:mouse/*` matches `:mouse/down` but never `:keyboard/down`. A non-namespaced id (`:go`) has no `:ns/*` tier. Note a **forbidden block** (`{:on {E {}}}` / `{:on {E nil}}`) is *enabled*, so it wins its tier and halts the walk rather than falling through to a wildcard. |
| **`reenter: true`** (v5/v6; v4 `internal: false`) | `:reenter? true` on the transition | Convergence on the name **and** the internal-by-default geometry. Four distinct cases — do not collapse them: **targetless** = the `:action` runs, configuration and descendants untouched (the runtime's only `internal?` no-op); **self / proper-ancestor `:target` without `:reenter?`** = the target's own `:exit`/`:entry` do NOT fire, **but its descendants re-resolve to `:initial`** (so it is *not* a configuration no-op — omit `:target` entirely to preserve children); **proper-descendant `:target` named by the declaring compound** = that child IS re-entered, even when already active; **`:reenter? true`** = exit + entry fire, `:after` timers restart from zero and `:spawn` children tear down and respawn. |
| **guards** (`guard` / named guards) | `:guard` on a transition + the top-level `:guards` map | Convergence on the *name*. **Divergence:** no `{and: [...]}` compound-guard data form — compose with one fn or one named registered compound. Guards receive one context map `{:keys [data event state meta]}` and destructure what they need. |
| **actions** (`actions` / named actions) | `:action` / `:entry` / `:exit` + the top-level `:actions` map | Convergence on the *name*. **Divergence:** no action-vector `[a1 a2 a3]` per slot — one fn or one named registered compound. `:entry`/`:exit` are a single fn or single keyword, never vectors. |
| **`assign({...})`** | action returns `{:data new-data}` (and/or `{:fx [...]}`) | **Divergence (name/shape):** no `[:assign {...}]` form. Symmetric with `reg-event`'s `{:db :fx}` return. The invariant matches xstate's `assign` though: callbacks may only update `:data` — they cannot nudge the machine into an undeclared state. |
| **`context`** (extended state) | `:data` (the machine's private map, distinct from `app-db`) | **Divergence (name):** re-frame2 calls the slot `:data` — there is no `context` slot. |
| **typed `context`** (v6 `schemas`) | `[:schemas :data]` (the machine-level `:schemas` map's data-context schema; EP-0029 A3) | Convergence on the role — both declare the context's shape and make it tool-renderable. **Divergence (enforcement):** XState's typed context is compile-time-only and erased at runtime; re-frame2's `[:schemas :data]` is an *actually-running* validation in dev (via the optional registered validator, e.g. Malli; and an opt-in at production boundaries), at zero production cost. **Divergence (name):** the slot is `:data` (not `context`), so the schema lives at `[:schemas :data]`. See [`machine-schemas.md`](machine-schemas.md). |
| **`invoke`** (state-bound child actor) | `:spawn` (and `:spawn-all` for fan-out-and-join) | **Divergence (name):** the slot is `:spawn`, aligned with the imperative `:rf.machine/spawn` fx — there is no `:invoke`. No `:onSnapshot`/`autoForward`/multiple-`:invoke`-per-state. See [`spawn.md`](spawn.md). |
| **`invoke onError`** (child→parent failure **transition**) | `:spawn`'s `:on-error` transition + `:error? true` final leaf | Convergence — re-frame2 ships `invoke onError` first-class as a control-flow **transition** (not observability-only). The child designates an error terminal with `:final? true :error? true`; the parent's `:spawn` declares `:on-error` (an `:on`-shaped transition spec). See [`spawn.md`](spawn.md) §`:on-error`. |
| **`onDone`** (child→parent completion) | `:final?` leaf + parent `:spawn`'s `:on-done` + `:output-key` | Convergence — re-frame2 ships first-class final-state-with-parent-notification. See [`spawn.md`](spawn.md). |
| **`output`** (typed completion output) | `[:schemas :output]` validating the `:output-key` payload (EP-0029 A8) | Convergence on the role — both declare the completion-output shape. **Divergence:** re-frame2 keeps completion *event-shaped* (no long-lived `snapshot.output`); `[:schemas :output]` validates the `:output-key` payload *as it flows* at finalize time, best-effort fail-loud (`:where :machine-output`, `:rollback? false`). See [`machine-schemas.md`](machine-schemas.md). |
| **parallel states** (`type: 'parallel'`) | `:type :parallel` + `:regions {...}` | Convergence (name + concept). `:data` shared; `:tags` is the union across active regions. See [`regions.md`](regions.md). |
| **`stateIn(...)`** (v5 `xstate/guards`; v4 `in:`; SCXML `In()`) | inside a parallel region, read `(:tags ctx)` or `(:all-state ctx)` in the guard; a flat machine uses its own `:state` | **Convergence on the behaviour, divergence on the API** — there is no `stateIn` primitive, and this is the one row the v6 preamble above must not be read as denying. A guard/action running **inside a region** gets two extra ctx keys: **`:tags`**, the machine-wide tag union (`(contains? tags :form/valid)`) — **the** documented `stateIn` equivalent, since a tag is a *named* render-state — and **`:all-state`**, the region-name → active-state map, the literal analog (`(= :valid (:form (:all-state ctx)))`). Both are **frozen at the start of the selection round**, so a region never sees a sibling's transition from the set currently being selected; convergence lands on the next round (`:raise` or a guarded `:always`). A **flat / compound** machine's ctx stays exactly `{:data :event :state :meta}`. See [`regions.md`](regions.md). |
| **history states** (`type: 'history'`, `history: 'deep'`) | `:type :history` pseudo-state under a compound's `:states` (`:deep?` / `:default-target`) | Convergence (name + concept). Shallow by default; `:deep? true` for deep. Recording rides the snapshot's `:rf/history` slot — so undo / time-travel / SSR get it free. See [`history.md`](history.md). |
| **final states** (`type: 'final'`) | `:final? true` on a leaf state | Convergence on the concept. **Note the divergence:** a **root-level** `:final?` singleton auto-destroys — "final means final." An *embedded* `:final?` raises an in-machine done-state signal and the machine keeps running. Omit `:final?` for a persistent terminal state. See [`spawn.md`](spawn.md). |
| **tags** (`tags: [...]`) | `:tags #{...}` on a state node + `[:rf.machine/has-tag? id tag]` | Convergence. See [`tags.md`](tags.md). |
| **eventless / always transitions** | `:always [{:guard ... :target ...} ...]` | Convergence (re-frame2's term for xstate/SCXML transient transitions). |
| **delayed transitions** (`after`) | `:after {<ms> transition-spec}` | Convergence on the name. No recurring timers / pause-resume in v1. |
| **state / actor timeouts** (`timeout` / `onTimeout`) | `:timeout <ms-or-ISO-8601>` + `:on-timeout <transition>` on a state, or on a `:spawn` spec | Convergence on the concept (a named deadline that lowers onto `:after`). **Divergence:** the duration is integer-ms **or** an ISO-8601 string (`"PT5S"`); the XState `"5s"`/`"10ms"` readable shorthand is **rejected**. |
| **choice / transient states** (`type: 'choice'`) | `:type :choice` + `:choice [{:guard ... :target ...} ... {:target <default>}]` on a state | Convergence on the concept (an immediate decision node that resolves on entry to the first guard-passing candidate; lowers onto `:always`). **Divergence:** the routing is a declarative candidate **array**, NOT XState's `choice`-*function* (a function may never be the edge). A choice state must include an unguarded default candidate and only routes (no `:entry` / `:on` / `:after` / `:timeout` / `:spawn` / …). |
| **`raise` (self-event)** | `:raise` inside an action's `:fx` | **Divergence:** sugar for atomic self-dispatch — there is no per-actor mailbox to insert in front of. |
| **internal events** (v6 `internalEvents`) | top-level `:internal-events #{:tick …}` (a **set** of event-ids) | Convergence on the concept (private events the machine raises + handles itself; an external dispatch of one is refused at the machine dispatch boundary, while an internal `:raise` of it is handled normally). **Divergence:** the declaration is a Clojure **set** (`#{:tick}`), NOT XState's array — membership is the natural shape, order irrelevant, duplicates impossible. A reserved framework event (e.g. the synthetic creation marker) cannot be declared internal. |
| **`sendTo` / `sender` (reply to a request)** | include the reply event in the request vector | **Divergence:** no new API; the event vector carries its own reply target. |
| **`ActorRef` runtime objects** | snapshots at `[:rf.runtime/machines :snapshots <id>]` in the runtime-db partition | **Divergence (architecture):** data-oriented, agent-friendly, no live-object leak footguns. Read via `(subscribe [:rf/machine <id>])`. |
| **`setup({actors, guards, actions})`** | per-machine `:guards` / `:actions` maps in the spec | **Divergence:** machine-scoped (not globally registered) — each machine has its own guard/action namespace, validated at registration; cross-machine reuse is via plain Clojure vars. |
| **three creation modes** (`createActor` / `invoke` / `spawn`) | one mechanism, two patterns: singleton via `reg-event`, dynamic via `:spawn` / `[:rf.machine/spawn ...]` | **Divergence:** lifetime is encoded by the snapshot's presence in the runtime-db partition (`[:rf.runtime/machines :snapshots <id>]`) + registration lifetime, not by which constructor you call. |

The divergence rows are catalogued in Spec 005 §Lessons from xstate and §Deliberate omissions vs xstate (and the full table in CP-5-MachineGuide §Lessons from xstate). When you reach for an xstate slot that isn't in the table — an action vector, `{and: [...]}`, multiple `:invoke` per state — that's a signal to stop and check the divergence rows rather than assume parity. (`invoke onError` *is* in the table — it maps to `:spawn`'s `:on-error` transition; don't hand-roll a dispatch-back where the declarative transition fits.)
