# Resources job comparison

Sixteen jobs were fixed in the [initial plan](evidence/initial-evaluation-plan.md). Contract and implementation refer to the [preserved baseline](evidence/baseline.json). **Executed** means this audit ran the named layer; source-traced and documented claims are not browser passes. A partial result can reflect incomplete evidence as well as incomplete capability; the reason is stated in each row. No composite score is calculated.

## Alternatives and provenance

| Comparator | Version / evidence | Useful challenge | Provider and cost |
|---|---|---|---|
| TanStack Query | 5.102.8 installed; core and React browser cases executed | Ordinary server-state behavior, typed options, optimistic strategies, scoped clients and mutation serialization | Core/react official packages; Devtools official adjacent package; persistence needs an adapter and application resume policy; broadcast experimental |
| RTK Query | Redux Toolkit 2.12.0 metadata; official docs/source inspected | Named endpoints and declarative tags, streaming lifecycle, generated API clients | Redux Toolkit includes RTK Query; Redux store integration; OpenAPI codegen is official adjacent tooling |
| SWR | 2.5.1 metadata; official site source inspected after site fetch failed | Small read/mutation surface, automatic race handling, provider caches and subscriptions | Library APIs plus application cache/provider and transport choices |
| Apollo Client | 4.3.0 metadata; official docs inspected | Shared entity identity across queries, field policies and mutation cache work | GraphQL client plus schema/backend expectations; membership is not automatically inferred for every filtered list |
| Riverpod | 3.4.3 release metadata; official docs inspected | Non-JS disposal/retention and provider productivity | Dart/Flutter ecosystem; persistence storage adapter; mutation/persistence APIs labeled experimental |
| TanStack DB | 0.9.0 metadata; beta docs inspected | Live collections, optimistic transactions and REST query integration | Separate DB and Query collection packages; collection identity, sync policy and mutation handlers |

Sources: [TanStack official guides](https://tanstack.com/query/latest/docs/framework/react/overview), [RTK tags](https://redux-toolkit.js.org/rtk-query/usage/automated-refetching), [SWR mutation source](https://github.com/vercel/swr-site/blob/main/content/docs/mutation.mdx), [Apollo cache](https://www.apollographql.com/docs/react/caching/overview), [Riverpod disposal](https://riverpod.dev/docs/concepts2/auto_dispose), [DB Query collection](https://tanstack.com/db/latest/docs/collections/query-collection).
